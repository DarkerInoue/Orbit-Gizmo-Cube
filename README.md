# Orbit Gizmo Cube

**Author:** Darker Inoue  
**Version:** 1.0.1  
**License:** GNU General Public License v3.0 or later  
**Minimum Blender version:** 5.1.0
**Github:** https://github.com/DarkerInoue/Orbit-Gizmo-Cube

Orbit Gizmo Cube adds an orange viewport orbit gizmo cube and a compact toolbar to the 3D View. It also includes scene-unit conversion and viewport-grid controls.

## Features

- Click a face, edge, or corner to orient the 3D View toward that direction.
- Drag the cube to orbit the view.
- Use the toolbar to return to the home view, zoom, pan, toggle camera view, and switch between perspective and orthographic projection.
- Configure the cube's visibility, size, opacity, animation time, and related display options.
- Change scene length units (mm, cm, m, km, in, ft, and mi).
- Keep the viewport grid synchronized with scene units, or configure the grid manually.
- Convert a length between supported units and copy the result.

## Installation

1. In Blender, open **Edit > Preferences > Get Extensions**.
2. Search for **Orbit Gizmo Cube** and install it after it is published.
3. Enable the extension if Blender does not enable it automatically.

To test a package before publication, use **Edit > Preferences > Get Extensions > Install from Disk** and select the ZIP archive.

## Interface

Open the **3D Viewport**, press **N** to show the Sidebar, and select the **Orbit Gizmo Cube** tab.

## Compatibility

This release declares Blender **5.1.0** as its minimum supported version.
